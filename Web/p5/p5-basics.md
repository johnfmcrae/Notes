# p5 Basics

p5.js is a library for creating visual art and animation using JavaScript. A basic p5 file includes a `setup()` and a `draw()` function, which are defined as follows:

- [`setup()`](https://p5js.org/reference/p5/setup/): A function that's called once when the sketch begins running.
- [`draw()`](https://p5js.org/reference/p5/draw/): A function that's called repeatedly while the sketch runs.

## Common Functions
